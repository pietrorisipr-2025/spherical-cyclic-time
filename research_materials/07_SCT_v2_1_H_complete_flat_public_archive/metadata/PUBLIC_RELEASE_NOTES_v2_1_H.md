# Public Release Notes — SCT v2.1-H

This package is intended as a clean public release base for Zenodo.

It supersedes recursive internal recovery bundles for public-upload purposes. The internal recovery packages remain valid for continuity, but they are not included here.

Main update:

- `T_R(k)` is now presented as a model-dependent transfer operator.
- The gaussian/diffusive kernel is no longer the conservative closed-background default.
- The gaussian kernel remains only a conditional open-system/diffusive toy limit.
- The plateau-like kernel remains only a closed deterministic proxy toy branch.
- v2.0 is a limited negative computational result for two preregistered toy backgrounds, not a general no-go theorem.

Publication status:

- Prepared for Zenodo new-version upload.
- No Zenodo action has been executed from this environment.
