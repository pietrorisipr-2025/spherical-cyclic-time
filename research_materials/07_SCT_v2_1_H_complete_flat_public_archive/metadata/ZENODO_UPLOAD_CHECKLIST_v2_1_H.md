# Zenodo Publication Checklist — SCT v2.1-H

## Before creating the draft

- [x] Public package is flat and contains no nested ZIP archives.
- [x] Absolute `<local_sandbox_path>` paths are not present in text files.
- [x] v2.0-G and v2.1-E public addenda are included.
- [x] v2.0 result tables, scripts, and figure are included.
- [x] v1.6 main papers are included as baseline full papers.
- [x] Claim boundary is explicit.
- [x] Versioning recommendation is documented.

## In Zenodo

- [ ] Open existing record `10.5281/zenodo.20499294`.
- [ ] Click **New version** rather than making an unrelated new upload.
- [ ] Use version `2.1.0`.
- [ ] Upload this final package ZIP, or upload `upload_set/` files individually.
- [ ] Use license CC BY 4.0.
- [ ] Keep resource type as Preprint / Technical note.
- [ ] Preview before publishing.
- [ ] Confirm the final new version DOI after Zenodo creates/registers it.

## Known unresolved fields requiring user decision

- [ ] ORCID: optional; not included unless the user provides it.
- [ ] Final publication date: set to the actual date of Zenodo publication.
- [ ] Community selection: optional.
- [ ] Whether to upload one ZIP or individual files: both are acceptable; one ZIP is simpler and preserves directory structure.

## Not required for publication

- A new physical background/action.
- More parameter scans.
- Additional recovery bundles.
- A third background family.
